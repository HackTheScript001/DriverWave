What's new in 1.1.6
- Uninstaller works like Revo Uninstaller: click Uninstall and choose whether to make a backup (restore point) first. The program's own uninstaller runs, then a window shows the registry entries and files it left behind and asks whether to delete them – Yes or No.
- The separate "Remove leftovers only" button has gone; programs with a missing uninstaller go straight to the leftovers window.

What's new in 1.1.5
- The installer now says SecondWave IT Systems in its window title, welcome and finish pages.

What's new in 1.1.4
- Graphics card: while NVIDIA's installer runs, DriverWave now shows what it's doing (unpacking or installing), a running timer and a moving progress bar, so a long install no longer looks stuck. NVIDIA's own install logs are kept for troubleshooting.
- DriverWave asks before closing if it's still in the middle of installing or removing something.

What's new in 1.1.3
- DriverWave has its own logo and icon. The SecondWave IT Systems credit stays at the top right.

What's new in 1.1.2
- The real SecondWave IT Systems logo in the app and as DriverWave's icon.

What's new in 1.1.1
- Graphics card: NVIDIA drivers are now found by the card's hardware ID, the same way NVIDIA's own app does it, so DriverWave downloads and installs the right driver itself – including cards like the GTX 1060 6GB that the name search missed, and cards that don't have a driver yet.

What's new in 1.1.0
- Updates the same way Hatchling does: DriverWave checks for a new version when it opens and downloads it in the background straight away. Click the update button to see what's new and install it – DriverWave closes and reopens on the new version. If you close DriverWave first, the update installs quietly on close.
- Updates are only installed from GitHub, and only if the download matches the checksum published with the release. Dropped connections carry on from where they stopped.
- New Settings page: check for updates now, turn install-on-close on or off, open the backups folder and log.

What's new in 1.0.4
- Graphics card: the latest driver straight from NVIDIA (installed silently), AMD or Intel.
- Driver backup: save every driver before reinstalling Windows and put them all back afterwards.
- Uninstaller: removes a program, then the folders and registry keys it left behind.
- System cleanup, a cautious registry cleaner, and startup programs on/off.

How to install
Download DriverWave-x.y.z-Setup.exe below and run it. Windows will ask for admin rights – drivers can't be installed without them.
